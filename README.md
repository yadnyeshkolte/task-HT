# Habit Tracker

A single-page weekly habit tracker built with React, TypeScript, and Vite.

## Run locally

Requirements:

- Node.js 20 or newer
- npm

From the project root:

```bash
npm install
npm run dev
```

Then open the local URL printed by Vite, usually:

```text
http://localhost:5173
```

## Build check

```bash
npm run build
```

## Notes

- Habits and daily checkmarks persist in `localStorage`.
- Weeks start on Monday.
- Future dates are visible but disabled.
- No deployed URL is included for this submission.
